# Sudoku Game

A simple Sudoku game built with **React**, **TypeScript**, and **Vite**.

![screenshot](./public/demo.png)

## Getting Started

### Install dependencies

```bash
pnpm install
```

### Run the development server

```bash
pnpm run dev
```

The app will be available at `http://localhost:5173`.

### Build for production

```bash
pnpm run build
```
